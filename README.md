# SK Survey

Опросы Международной гимназии Сколково: конструктор, прохождение по ссылке и результаты.
Работает самостоятельно, без NocoBase; вход и справочник людей - через SkolStream (пакет
[sk-common](https://github.com/aleksioprime/sk-common)).

## Возможности

- **Конструктор** - опросы с разделами и одиннадцатью типами вопросов: один вариант, несколько вариантов,
  шкала (числа или подписи, диапазоны для отчёта), текст, развёрнутый текст, число, да/нет,
  расстановка по порядку, матрица с одним или несколькими вариантами в строке, список текстовых
  ответов с минимумом и максимумом строк.
  Список вопросов сгруппирован по разделам, каждый вопрос открывается отдельно. Варианты можно
  вставить списком. Опрос и отдельные вопросы можно копировать. Перед публикацией
  форму можно пройти в режиме предпросмотра, ответы при этом не записываются.
- **Публикации** - ссылка `/s/<токен>` для конкретной группы и периода: анонимная (без входа) или
  с входом через SkolStream (одно прохождение на человека, в выгрузке - ФИО и класс). Сроки приёма,
  наблюдатели из справочника сотрудников. Лимит начала анонимных прохождений
  `RESPONSES_PER_IP_HOUR` действует на каждый IP отдельно в пределах публикации (по умолчанию 60).
- **Прохождение** - по частям-разделам, ответы сохраняются сразу, можно вернуться позже на том же
  устройстве. Ключ прохождения хранится только в браузере, на сервере - его хеш.
- **Результаты** - сводка по каждому вопросу (доли вариантов, среднее и распределение по шкале,
  диапазоны, средняя позиция в расстановке, текстовые ответы) и выгрузка в Excel. Для матриц
  сводка и выгрузка строятся по строкам. Исключённые варианты показываются отдельно с долей
  от всех ответивших на строку. Анонимная выгрузка не содержит времени отправки.

## Кто что может

| Роль | Права |
|---|---|
| Сотрудник (из SkolStream) или администратор | создаёт опросы, становится их первым редактором |
| Редактор | меняет опрос и публикации, видит результаты, управляет списком редакторов и может удалить опрос без отправленных ответов |
| Наблюдатель публикации | видит результаты этой публикации |
| Администратор сервиса | доступ редактора ко всем опросам, раздел «Люди» и синхронизация со SkolStream |

Список редакторов находится в настройках опроса. При сохранении должен остаться
хотя бы один редактор. Наблюдателей добавляют отдельно в каждой публикации.

Удалить можно только то, на что ещё не отвечали; иначе - выключить. Вариант ответа, который уже
выбирали, при удалении выключается и остаётся в результатах.

## Разработка

```bash
docker compose -p sk-survey up -d --build
```

Приложение - http://localhost:8601, API - http://localhost:8600/api/docs, почта - http://localhost:8604.
Администратор - `admin@example.org`, пароль в `docker-compose.yaml`.

Тесты backend (нужны PostgreSQL и Redis, например из этого же compose):

```bash
cd backend && DB__PORT=8610 REDIS__PORT=8611 pytest -q
```

Тесты и сборка фронтенда: `cd frontend && npm ci && npm run lint && npm test && npm run build`.
